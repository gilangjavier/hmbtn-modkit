# Cheat Pad

Button-combo cheats on controller 1. They only work on the farm.

| Combo                    | Effect                         |
|--------------------------|--------------------------------|
| `L1` + `R1` + `SELECT`   | +10,000 G (capped at 9,999,999) |
| `L1` + `R1` + `TRIANGLE` | Stamina full, fatigue 0         |

Hooks: `frame`.
